# Prism pointer

Prism draws the mouse pointer in software after all windows, dialogs, and taskbar
surfaces, so the hot spot stays visible above the active surface. The pointer is
an original compact raster arrow: a white face, near-black edge, and subtle cool
offset edge help it remain distinct on both light and dark content. Canvas
clipping keeps motion at display boundaries bounded.

The artwork follows the familiar Windows arrow silhouette without embedding
Windows cursor files or implying use of Microsoft's licensed assets. Prism's
current text face remains the separately licensed Open Sans raster atlas.
