# Connected UDP development profile

Seventh-wave image `31e7e89ec2396a625bbdd90b5624c0377c8dfa8d5c54c64f28746cfccae1a7a9` has a completed scoped [milestone](evidence/milestones/31e7e89ec239/README.md): both CPU profiles, host tests, refusals, persistence and runtime checks pass. The previous immutable sixth milestone does not contain application sockets. This is a bounded native connected IPv4 datagram interface, not a userspace netd, general socket API, POSIX/Winsock bridge or production network stack.

A retained legacy virtio owner supplies bounded nonblocking progress after boot probes. Socket objects have generation/refcounted identities and separate READ/WRITE/DUPLICATE/TRANSFER/WAIT capabilities. Signed NETWORK permission bit 4 and an independent runtime grant are required on creation, insertion, duplication, transfer and use; a signed declaration alone does not grant network access. The guest checks an intentionally attenuated worker and a denied socket import into an unprivileged recipient.

The trusted development peer is fixed at 10.0.2.2:39097 through QEMU user networking. The local DHCP address must be 10.0.2.15, with ephemeral ports 49200–49207; auto port selection uses only that range. No user-controlled peer, listening/bind wildcard, multicast, raw packets, general routing or renewed lease is provided. Eight global sockets each hold four receive and four transmit datagrams, maximum 1472 bytes per payload. Full TX returns WouldBlock; full RX drops the newly arriving datagram while preserving queued data. Malformed/wrong-peer packets never enter queues. Empty datagrams are valid packets, distinct from an empty receive queue.

Native calls 33–35 implement create/send/receive. Create takes RDI local port (0 selects auto) and RSI wire rights subset 0x3b; even a zero-rights socket still requires NETWORK authorization. Send takes RDI capability, RSI payload pointer, RDX length. Receive takes RDI capability, RSI output pointer, RDX capacity. Length/capacity greater than 1472 rejects. No memory is accessed for zero-length input/output; a queued empty datagram returns zero, a nonempty datagram into zero capacity returns BufferTooSmall, and an empty queue returns WouldBlock.

Receive stages an exact socket-scoped queue ticket and validates complete user output before committing consumption. Short or invalid output preserves the packet. Queue acceptance on send is not remote acknowledgement. Device DMA uses permanent driver staging buffers, never user/socket pointers; closing a socket cannot free in-flight DMA memory. Late completion tickets cannot affect a recycled socket object. Duplicate references share one receive queue and close only releases the caller's reference.

Seventh live checks send a nonce-bearing packet and an empty datagram to the loopback host peer, receive exact echoes, verify level-readable wait does not dequeue, reject rights/copyout violations and exercise stale handles/reuse. These do not establish general UDP interoperability, sustained loss/backpressure behavior, interface recovery, independent per-app traffic quotas, IPv6 transport, arbitrary application networking or physical device certification.

Eighth-wave source readiness contract, awaiting new guest validation: ObjectWait flag bit 1 selects writable datagram readiness, while bit 0 keeps existing blocking mode (read poll/block flags 0/1; write poll/block flags 2/3). Non-datagram objects reject the writable selector. WAIT and NETWORK authority are checked before parking and completion; result zero is level readiness with no packet consumption. SDK wait_readable/wait_writable take Poll/Block/Until modes, with poll_writable convenience. SDK methods are implemented and host-tested for direction/mode/deadline encoding. Actual delayed-response wake, deadlines, TX-pressure wake, backend/lease failure and killed-waiter cleanup need new guest proof before advertising those additions.
