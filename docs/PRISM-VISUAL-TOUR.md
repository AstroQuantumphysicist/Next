# Prism visual tour

These images are current QEMU guest captures of Prism. Each caption names the
surface or state shown. They document a development build and do not imply that
Next 1.0 is complete, that the UI is hardware-validated, or that every pictured
control represents a finished product feature.

## Home

![Prism Home with pinned applications and the centered taskbar](images/prism-home.png)

Home shows the desktop wallpaper, pinned applications, and taskbar.

## Files

![Prism Files browsing the native store](images/prism-files.png)

The standard Files view browses the native store.

![Files with the /native root tab active and a second tab open](images/prism-files-tabs-root.png)

The root tab stays available beside a second browsing context.

![Files with /native/alpha active and the /native root tab retained](images/prism-files-tabs-nested.png)

The nested tab preserves its own location while the root tab remains open.

![I-beam cursor over the editable Files location field](images/prism-files-tabs-ibeam.png)

The location field uses the I-beam cursor while it is editable.

![Files with independent left and right panes at /native and /native/alpha](images/prism-files-dual-pane.png)

The two panes keep their own locations when navigation changes in the other
pane.
